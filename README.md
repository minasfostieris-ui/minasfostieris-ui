# Minas

I make cool random stuff whenever I'm bored. Local-first, no telemetry, no accounts.

## Projects

### 🦙 [OhMyLLM](https://ohmyllm.vercel.app)
Local-first agentic AI platform for Ollama and LM Studio — a real tool loop, a permission engine that never lets the model play god, persistent Markdown memory, hold-to-talk voice input, and a VRAM-aware model market. Terminal UI + native GUI on one engine. MIT licensed.

- Website: **[ohmyllm.vercel.app](https://ohmyllm.vercel.app)**
- Source: [github.com/minasfostieris-ui/ohmyllm](https://github.com/minasfostieris-ui/ohmyllm)

### 🖼️ [gonbe](https://github.com/minasfostieris-ui/gonbe)
A custom `.gonbe` image format built from scratch — rANS entropy coding, MED predictor, lossless and lossy modes, with a Flet GUI viewer and C acceleration.

### 📋 [clipboard-gadget](https://github.com/minasfostieris-ui/clipboard-gadget)
A frameless, dark-themed clipboard manager that lives on your desktop as a floating gadget. Drag a card toward any text field and it swings on real pendulum physics, then pastes on release. Python + PySide6, no Electron.
